Implementations of OPES (Invernizzi et al 2020) and parallel tempering (Swendsen and Wang 1986) in a c-python framework. To run the pt scripts run run_pt.py and change parameters in define_data_and_variables.py. Similarly for OPES run run_opes.py and change parameters in the corresponding define_data_and_variables.py. 

The synthetic data was generated by the code in the "generate_synthetic_data" folder. Plots and data are generated when run_hmc.py is run. The data is stored in data together with some plots for each of the datasets.

Running on both linux and windows should work but linux is preferable as windows requires msys or similar.

As mentioned in the article, the initial parameters for dF are sensitive and problem-specific so with another dataset some care might be needed for these.
